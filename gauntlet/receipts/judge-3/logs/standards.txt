COMING

COMING

Extended warranties

EDUCATOR GUIDE · GRADES 5–8

Plan Under Pressure

An application task for adaptive budgeting under uncertainty. 20–28 minutes, in one sitting or across days. Use after instruction.

Create a class
Try it as a student
See a sample class

READ THIS FIRST

THE WHOLE RESOURCE IN ONE MINUTE.
What does it assess?
Whether students can apply budgeting under uncertainty — build a workable plan, keep it working when income and costs change, and justify it.
When do I use it?
After you have taught the skills.
How long?
20–28 minutes for most students, in one sitting or across days. The class code and the code on their card open the run they left, on any computer.
Do students need headphones?
Yes, or a quiet room. Any student can press Reading help to hear the screen read out loud, or to look up a word on it. You turn nothing on, it stays on the device, and who used it is never recorded — so it cannot count against a student. Nothing is translated: a student new to English gets the same two tools, in English.
What do students do?
They handle the money in one of two stories. Students pick, or everyone gets one. Eight Weeks to the Showcase: a player’s season. They choose housing, build a plan, absorb a Week 5 loss and a new required cost, and repair it. Run the Pop-Up: four Saturdays at a night market. They take a booth, decide how much food to cook against the crowd it draws, and cover a generator that dies with the biggest night still ahead. Three crowds are printed before they order; the last is a range.
Do the two give me the same thing back?
Yes, on the skills. Both stories are judged against the same named parts of the work, so a class that chose differently still gets one set of skill results. What the room decided comes back one story at a time, each with its own count — plan the debrief as two groups.
What do I get back?
For each student, what the evidence shows against each skill — one line for each thing the work had to show, each traceable to the moment in their own run. Plus what the class decided, and one written explanation you read and score yourself. Counts for your gradebook come with it.
How do I launch it?
Create a class, paste your class list, print the cards — one per student. Put the class code on the board; a student types that code and the code on their own card. They never type an email address, a password or a birthday. No list to hand? Students type the class code and their own first name instead.

BEFORE STUDENTS BEGIN

Teach these first. This is an application task, not a lesson.

01
Distinguish dependable and conditional income.
02
Combine recurring and one-time costs.
03
Build a budget that does not exceed available money.
04
Separate committed money from money that can change.
05
Revise after income or expenses change.
06
Explain a trade-off with relevant numbers.

Schools may use their own instruction.

A two-day sample mini-unit, if you want one
RUNNING IT
Create a class, paste your class list, print the cards and hand them out. Students type the class code from the board and the code on their card. Without a list they type their own name instead — print those students a card before they leave, or typing the name again starts a second run.
Allow 20–28 minutes, in one period or across days: a student who stops signs in again on any computer and presses Carry on. Do not coach a financial strategy.
Read and score the written explanations. Nothing a student writes is machine-scored.
Open the class: what the evidence shows, and what to teach next.
Run the debrief with the room.

A high grade reflects the financial skills a student actually showed — not a preference for saving more, spending less, taking a job, or choosing the cheapest option.
